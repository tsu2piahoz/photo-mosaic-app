フォトモザイク制作室（iPadローカル版 v6.3）

■ v6.3の変更点
・配置の初期割当を左上からの単純な順番ではなく、最適な写真候補が限られるマスを優先する方式に変更。
・初期割当後の写真交換による調整回数を増やし、各マスの色一致と隣接タイルの色変化をさらに調整。
・原画と写真の明暗ばらつきを、双方とも同じ8×8サンプルで計算するよう統一。
・写真ごとの特徴量（Lab平均色・明暗ばらつき）を端末内に保存。2回目以降の配置では、写真の再解析を省略できる。
・特徴量はタイル比率ごとに管理し、タイル比率を変更した場合は再計算。
・配置は一対一（同じ写真を複数マスに重複使用しない）を維持。

■ v6.1の変更点
・登録済み写真一覧を100枚ずつページ表示。全3,000枚でも30ページで確認可能。
・写真ごとのチェック選択、表示中ページの一括選択、選択写真の一括削除に対応。
・配置済み写真を削除する場合は、配置データと品質評価結果をリセットして再配置を促す。未配置写真のみの削除では既存配置を維持。
・トリミング確認を24枚ずつから100枚ずつに変更（3,000枚なら125ページから30ページ）。

■ v6の変更点
・画面を4段階に整理：「写真準備」→「モザイク作成」→「仕上がり確認」→「印刷・保存」。
・仕上がり確認に自動品質評価を追加。
・評価では、原画をタイル単位に分け、配置された写真との平均色差（CIE LabのΔE76）と明暗ばらつきの差を計算。
・評価が低い場合は、未使用写真の活用や写真候補の追加を提案。
・写真への番号印刷なし。番号は別紙の配置図・CSVで管理。

■ 基本仕様
・初期値：60列×50行（3,000マス）。
・タイル寸法：横38.1mm×縦26.7mm。
・写真はZIPまたはファイルアプリから取り込み。
・写真・原画・配置情報はブラウザのIndexedDBに保存。
・画像の色補正・半透明合成は行わない。
・配置はCIE Lab色差、原画の明暗・輪郭、隣接タイルの色変化を考慮した一対一の初期割当と交換最適化。v6.3では希少候補マスの優先処理と特徴量キャッシュを追加。
・写真シートはA4/A3、1・5・10ページ単位で分割印刷・PDF保存。
・写真シートには番号を印刷せず、別紙の配置図に通し番号と行・列を表示。
・トリミング確認は100枚ずつ表示。元写真は変更しない。
・プレビューは全体確認用の縮小表示。PNG保存に対応。
・CSVと配置情報JSONのバックアップに対応。JSONには写真本体は含まれない。

■ 品質評価について
評価値は、原画と写真タイルの平均色・明暗特徴を比較した参考値です。顔・物体・構図の認識や、人間の視覚による完成度判定ではありません。原画の細部や写真の内容、印刷後の見え方を完全に評価するものではありません。評価結果だけで完成を判断せず、全体プレビューを必ず確認してください。
評価が低い場合、写真候補を300〜600枚程度追加すると、より近い特徴の写真を選べる可能性があります。すでに未使用写真がある場合は、先に再生成して比較してください。

■ GitHub Pagesへの更新方法
1. ZIPをPCで展開。
2. index.html / app.js / sw.js / manifest.webmanifest / README_JA.txt / .nojekyll をリポジトリのルートにアップロード。
3. 同名ファイルを置き換えてCommit changes。
4. GitHub Pagesの更新完了後、公開URLを再読み込み。
5. 古い画面が残る場合は、強制再読み込みまたは少し時間をおいて再読み込み。

■ 重要な注意
・GitHub Pagesのリポジトリと公開サイトはインターネット上に公開されます。学校写真・生徒名・個人情報はGitHubへアップロードしないでください。
・写真はブラウザ内のIndexedDBに保存する設計です。SafariのWebサイトデータ消去や端末変更で失われる場合があります。元写真を必ず別途保管してください。
・v6はv5と同じIndexedDB名・保存形式を使用し、既存データの継続利用を想定しています。ただし更新前に元写真を保管し、配置情報もバックアップしてください。
・A4/A3の印刷は倍率100%、「用紙に合わせる」をOFFにしてください。最初に試し刷りし、定規で38.1mm×26.7mmになっているか確認してください。
・ZIP64・暗号化ZIPなど特殊なZIP形式は未対応の場合があります。
・JavaScript構文・HTML構造の静的検査は実施していますが、v6.3の配置精度・処理時間はiPad Safari実機で未検証です。実際のクラス写真でプレビューを確認してください。削除操作前に写真フォルダと配置情報をバックアップしてください。


【v6.2 写真自動最適化】
・新規写真は取り込み時に長辺最大1,024px、JPEG品質88%へ変換して保存します。
・元画像ファイルはIndexedDBに保存しません。180pxの一覧表示用サムネイルも生成します。
・v5/v6.1から引き継いだ写真は、起動時に順次最適化します。途中で中断した場合も、次回起動時に未処理分から再開します。
・写真の色補正は行いません。透明部分のある画像は白背景になります。
・最適化後は元の高解像度画像をアプリ内に保持しないため、必要な場合は元写真を別の場所に保管してください。
・モザイク配置の写真特徴解析には1,024px版を使用し、一覧表示用サムネイルは表示専用です。

【v6.3の処理上の注意】
・初回の配置では、候補の希少度を調べる工程が追加されるため、v6.2より初期処理が長くなる場合があります。
・写真特徴量を保存するため、同じタイル比率で再配置する場合は写真の解析時間を短縮できます。
・配置精度は色・明暗・隣接関係に基づく近似最適化です。顔や建物の意味的な認識を行うものではなく、数学的な全体最適解を保証するものでもありません。
