フォトモザイク制作室（iPadローカル版・試作2）

今回の更新
- 自動配置した写真をグリッドで確認するプレビューを追加
- プレビュー倍率（小・標準・大・最大）を切り替え可能
- プレビューをPNG画像として保存可能
- 配置を作り直した場合、プレビューの更新を促す表示を追加
- 列数・行数の入力チェックを追加
- Service Workerのキャッシュ名を更新

仕様
- 初期値：60列×50行（3,000マス）
- タイル横38.1mm×縦26.7mm
- ZIP / ファイルアプリから画像を取り込み
- IndexedDBへ端末内保存
- RGB平均色による重複なしの自動割り当て（色補正・半透明合成なし）
- 配置結果プレビュー、PNG保存、CSV、番号付き配置図、配置情報JSONバックアップ

GitHub Pagesへの更新方法（ブラウザのみ）
1. ZIPをWindows PCで展開する。
2. 展開したフォルダー内の index.html / app.js / sw.js / manifest.webmanifest / README_JA.txt / .nojekyll を使う。
3. GitHubの photo-mosaic-app リポジトリを開き、Codeタブで Add file → Upload files を選ぶ。
4. 上記ファイルをまとめてドラッグ＆ドロップする。同名ファイルは新しい内容に置き換える。
5. Commit changesを押す。
6. Actionsタブで github-pages の実行が完了するまで待つ。Settings → Pages → Visit site から公開サイトを開く。
7. 古い版が表示される場合は、Windowsでは Ctrl+F5、iPadではSafariで再読み込みする。必要なら数分待つ。

重要
- GitHub Pagesのリポジトリと公開サイトはインターネット上で公開されます。写真・生徒名・個人情報はGitHubへアップロードしないでください。
- 写真はブラウザ内のIndexedDBに保存する設計です。サイトデータ消去や端末変更で失われる場合があるため、元写真を別途保管してください。
- プレビューは縮小サムネイルによる全体確認用です。原寸タイル画像や分割印刷機能ではありません。
- バックアップJSONには写真本体は含まれません。
- 自動配置はRGB平均色による逐次最近傍方式です。輪郭・顔・構図の認識や全体最適化は未実装です。
- ZIP64・暗号化ZIPなど特殊な形式は未対応です。
- Windowsで3,000枚取り込み成功を踏まえた更新版ですが、iPad Safariでの3,000枚処理は未検証です。


【v3の変更点】
・配置計算をCIE Lab色差ベースに変更。
・原画の実寸比率（列数×タイル横寸法／行数×タイル縦寸法）に合わせて中央を切り出し。
・タイル写真も実際のタイル縦横比に合わせて中央を切り出し。
・原画の明暗境界を考慮し、隣接タイルのLab色変化を近づける交換最適化を追加。
・プレビューをタイルの実寸比率で描画。

注意：v3はPython版v6の考え方をWeb向けに再構成した近似実装です。Python版のSciPyハンガリアン法をそのまま移植したものではなく、初期配置は一対一の貪欲割当、その後に局所・全体交換で改善します。3,000枚・iPad Safariでの実機性能は必ず確認してください。写真・原画はGitHubへアップロードせず、端末内だけで扱ってください。


【v4 写真シート印刷】
「設計図・出力」からA4またはA3を選択し、写真シートを印刷できます。タイル寸法は初期値38.1×26.7mmです。印刷設定は倍率100%・用紙に合わせるOFFにしてください。プリンターの余白や印刷不可領域の影響があるため、最初に1ページ試し刷りし、定規で実寸を確認してください。番号は配置図の行-列と通し番号を併記しています。
