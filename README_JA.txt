フォトモザイク制作室（iPadローカル版・試作1）

仕様
- 60列×50行（初期値3,000マス）
- タイル横38.1mm×縦26.7mm
- ZIP / iPadファイルアプリから画像を取り込み
- IndexedDBへ端末内保存
- RGB平均色による重複なしの自動割り当て（色補正・半透明合成なし）
- CSV、配置番号図の印刷、配置情報JSONバックアップ

起動
1. ZIPを展開し、ファイル一式をHTTPS対応の静的Webサーバーに配置。
2. iPadのSafariでHTTPSアドレスを開く。
3. 共有→ホーム画面に追加。
4. 初回起動後は基本ファイルをキャッシュし、オフライン利用可能。

注意
- HTMLをファイルアプリから直接開くだけではPWA・IndexedDB・Service Workerが安定動作しない場合があります。HTTPSで配信してください。
- ZIP展開はSafariのDecompressionStream（deflate-raw）に依存します。非対応時は「ファイルから追加」を使用。
- 写真はIndexedDBに保存されます。SafariのWebサイトデータ消去で失われる場合があるため、原本写真を別途保管してください。
- バックアップJSONは配置情報のみで写真本体を含みません。
- 自動配置はRGB平均色による逐次最近傍方式の試作です。最適化割当や輪郭認識は未実装です。
- 配置図はA3横の番号・ファイル名一覧の簡易版です。タイル画像の原寸分割印刷は次段階の機能です。
