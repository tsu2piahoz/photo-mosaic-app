フォトモザイク制作室（マルチデバイス版 v13）

■ v9の主な変更点
・品質評価を拡張。平均色差・明暗差だけでなく、タイル内4×4色分布と隣接タイル間の色変化も評価。
・品質評価画面に4つの比較指標と総合目安スコアを表示。
・品質評価の説明文・判定助言を更新し、数値だけで完成度を断定しない設計に変更。

■ v7から引き継ぐ主な機能
・v6.3で欠落していた全体プレビュー作成関数を復旧。
・Service Workerキャッシュ名をv9へ更新。
・写真特徴量を更新し、平均Lab色・明暗ばらつきに加えて、タイル内4×4領域のLab色分布を保存。
・配置時に原画と写真の4×4空間特徴を比較し、写真内の明暗・色の配置も考慮。
・旧特徴量キャッシュはバージョン不一致として再計算し、端末内に保存。
・写真の一対一割当、隣接タイルの色変化を考慮した交換調整は継続。

■ v6.3から引き継ぐ機能
・写真一覧は100枚ずつ表示。個別・複数削除に対応。
・写真は取り込み時に長辺最大1,024px、JPEG品質88%へ最適化。色補正なし。
・既存写真の最適化移行、写真特徴量キャッシュ。
・4段階UI、全体プレビュー、品質評価、トリミング確認。
・A4/A3印刷、写真表面への番号非表示、裏面番号印刷、別紙配置図、CSV・配置情報JSON出力。
・60列×50行、タイル横38.1mm×縦26.7mmを初期設定。

■ 配置精度について
v7以降はタイル全体の平均色だけでなく、各タイルを4×4領域に分けた色分布も比較します。これにより、同じ平均色でも明るい部分・暗い部分の位置が異なる写真を区別しやすくします。ただし、顔・建物・窓などを意味的に認識するものではなく、最適解を保証しません。写真の向きや被写体の構図そのものを理解する機能ではありません。

■ 取り込み・保存
・写真・原画・配置情報はブラウザのIndexedDBに保存。画像処理は端末内で実行。
・アプリ内に保存する写真は最適化JPEGと一覧用サムネイル。元画像はアプリ内に保存しません。
・元写真は別途保管してください。SafariのWebサイトデータ消去や端末変更でアプリ内データが失われる場合があります。
・GitHub Pagesへ学校写真・生徒名・個人情報をアップロードしないでください。

■ 更新方法
1. ZIPを展開。
2. index.html / app.js / sw.js / manifest.webmanifest / README_JA.txt / .nojekyll をGitHubリポジトリのルートへアップロードし、同名ファイルを置き換える。
3. Commit changes後、Pagesの反映を待つ。
4. Safariで再読み込み。古い表示が残る場合はタブを閉じて開き直す。

■ 注意・検証状況
・JavaScript構文検査、HTMLの基本構造検査、ZIP整合性検査を実施。
・iPad Safari実機での3,000枚処理時間、PDF印刷寸法、実写真での配置精度は未検証。
・品質スコアは平均色差・4×4色分布・明暗差・隣接色変化に基づく参考値で、完成度の保証ではありません。全体プレビューを必ず確認してください。
・初回の配置では4×4空間特徴を新たに解析するため時間がかかります。2回目以降は同じタイル比率の特徴量キャッシュを利用します。
・更新前に配置情報CSV/JSONを保存し、元写真は別途保管してください。


【v9の追加】
・UIをカード型・段階型に整理し、iPadでの操作性を改善しました。
・写真表面には番号を印刷せず、裏面に通し番号と行・列座標を印刷できます。
・表面＋裏面を交互に出力する両面印刷モード、表面のみ、裏面のみを用意しました。
・長辺とじ／短辺とじ／補正なしを選択できます。
・初回は必ず1用紙だけ試し刷りし、写真と番号の位置が合うか確認してください。
・プリンター機種による裏面の向き・給紙方向の違いは残るため、必要に応じてとじ方向を切り替えて調整してください。
・既存のIndexedDB保存領域・写真データ・配置データは引き継ぐ設計です。


【v10の印刷改善】
・写真間隔を0mmに固定し、隣接写真の境界線は印刷しません。
・各タイル境界の裁断位置を、用紙上下左右の余白に短いトンボとして印刷します。
・L判（127×89mm）を基準に5〜100%で写真寸法を指定できます。初期値30%は38.1×26.7mmです。
・縮小率変更は配置済みグリッドの物理寸法にも反映します。
・トンボと両面位置合わせはプリンターの実機テストが必要です。最初は1ページで確認してください。


【v13の印刷・対応環境改善】
・写真間の境界だけでなく、最外周の写真と用紙余白の境界にもトンボを追加。各列境界は上下余白、各行境界は左右余白に短い目印を印刷します。写真上には線を印刷しません。
・再印刷単位を「ページ単位」「写真単位」から選択できます。写真単位では通し番号を指定し、カンマ区切りや範囲指定（例：12,18,25-28）で複数枚を個別に再印刷できます。写真単位の再印刷は、指定写真を1枚ずつ独立した用紙上に原寸で配置します。
・裏面の通し番号と行・列座標の文字サイズを拡大しました。
・Windows／macOS／iPadOSの主要な最新ブラウザ（Chrome・Edge・Safari）での利用を想定し、端末内のブラウザ保存を継続します。写真・配置データは利用した端末・ブラウザごとに保存されるため、自動同期はされません。別端末で使う場合は写真を再登録し、対応表・バックアップを使ってください。
・ブラウザやプリンターによって画像形式の対応、印刷余白、両面印刷の向きが異なります。HEIC等は端末のブラウザで読み込めない場合があります。最初に少数の写真と1ページで動作確認してください。


【v13の改善】
・写真登録は20枚単位でまとめてIndexedDBへ保存します。
・写真一覧は100枚単位で読み込み、全写真の画像データを一覧表示時に一括取得しません。

・裏面に写真境界すべての細い裁断線を追加し、表面には表示しません。

・配置アルゴリズム、色補正なし、再印刷機能は維持しています。


【v13の改善】

・番号と行列座標は各タイル中央にまとめ、裁断線から距離を確保。
・裏面裁断線を細く薄いグレーに調整。トンボも濃さを抑制。
