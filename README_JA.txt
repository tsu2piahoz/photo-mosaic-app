フォトモザイク制作室（iPadローカル版 v7）

■ v7の主な変更点
・v6.3で欠落していた全体プレビュー作成関数を復旧。
・画面表示・Service Workerキャッシュ名をv7へ統一。
・写真特徴量を更新し、平均Lab色・明暗ばらつきに加えて、タイル内4×4領域のLab色分布を保存。
・配置時に原画と写真の4×4空間特徴を比較し、写真内の明暗・色の配置も考慮。
・旧特徴量キャッシュはバージョン不一致として再計算し、端末内に保存。
・写真の一対一割当、隣接タイルの色変化を考慮した交換調整は継続。

■ v6.3から引き継ぐ機能
・写真一覧は100枚ずつ表示。個別・複数削除に対応。
・写真は取り込み時に長辺最大1,024px、JPEG品質88%へ最適化。色補正なし。
・既存写真の最適化移行、写真特徴量キャッシュ。
・4段階UI、全体プレビュー、品質評価、トリミング確認。
・A4/A3印刷、写真シートへの番号非表示、別紙配置図、CSV・配置情報JSON出力。
・60列×50行、タイル横38.1mm×縦26.7mmを初期設定。

■ 配置精度について
v7はタイル全体の平均色だけでなく、各タイルを4×4領域に分けた色分布も比較します。これにより、同じ平均色でも明るい部分・暗い部分の位置が異なる写真を区別しやすくします。ただし、顔・建物・窓などを意味的に認識するものではなく、最適解を保証しません。写真の向きや被写体の構図そのものを理解する機能ではありません。

■ 取り込み・保存
・写真・原画・配置情報はブラウザのIndexedDBに保存。画像処理は端末内で実行。
・アプリ内に保存する写真は最適化JPEGと一覧用サムネイル。元画像はアプリ内に保存しません。
・元写真は別途保管してください。SafariのWebサイトデータ消去や端末変更でアプリ内データが失われる場合があります。
・GitHub Pagesへ学校写真・生徒名・個人情報をアップロードしないでください。

■ 更新方法
1. ZIPを展開。
2. index.html / app.js / sw.js / manifest.webmanifest / README_JA.txt / .nojekyll をGitHubリポジトリのルートへアップロードし、同名ファイルを置き換える。
3. Commit changes後、Pagesの反映を待つ。
4. Safariで再読み込み。古い表示が残る場合はタブを閉じて開き直す。

■ 注意・検証状況
・JavaScript構文検査、HTMLの基本構造検査、ZIP整合性検査を実施。
・iPad Safari実機での3,000枚処理時間、PDF印刷寸法、実写真での配置精度は未検証。
・品質スコアは平均色差と明暗特徴に基づく参考値で、完成度の保証ではありません。全体プレビューを必ず確認してください。
・初回のv7配置では4×4空間特徴を新たに解析するため時間がかかります。2回目以降は同じタイル比率の特徴量キャッシュを利用します。
・更新前に配置情報CSV/JSONを保存し、元写真は別途保管してください。
